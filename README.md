# Hoop Land Access

A blind accessibility mod for **Hoop Land** (Steam PC basketball), made by a totally blind player with Claude Code.
Speaks through JAWS: menus, court position, shooting, passing, defense, boundaries, franchise and create-a-player.

## Easy install
1. Install MelonLoader 0.7.3 into Hoop Land (https://github.com/LavaGang/MelonLoader/releases), start the game once, close it.
2. Download [HoopLandAccess_0.9.1.zip](https://github.com/Mmaslo1/HoopLand-Access/releases/latest/download/HoopLandAccess_0.9.1.zip) and copy everything in it into the Hoop Land game folder.

**Updates:** from 0.9.1 on, the mod checks for a new version when the game starts and says so. Press **Shift+F12** in a menu to download it; it installs itself after you close the game.
3. Start Hoop Land. The mod speaks through JAWS or NVDA. Read "01 START HERE - HOW TO INSTALL.txt" in the zip.

- `src/` - the mod code (C#)
- `HOOPLAND_RECAP.txt` - what the mod does and all keys
- `HOOPLAND_PLAN.txt` - what is planned next
- `NOTEBOOK.md` - technical notes

## Want to help?
Thank you! Please send changes as a **pull request** and say what it fixes and how you tested it.
The player makes the final call on every change, so explain it in plain words.
Everything must work by keyboard and speech, no mouse or screen steps.
